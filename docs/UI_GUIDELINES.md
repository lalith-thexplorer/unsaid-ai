# UI Guidelines — Unsaid

This document defines the **visual and interaction standards** for Unsaid.  
All screens must follow these guidelines to ensure a **calm, premium, and consistent user experience**.

UI quality is a **core requirement**, not an enhancement.

---

## 🎨 Theme

- **Dark theme only**
- Calm, low-contrast backgrounds
- No bright whites or harsh colors
- Designed for late-night use (2 AM friendly)

---

## 🧊 Visual Style — Glassmorphism

Use **modern glass-style UI elements** across the app.

### Required Characteristics
- Semi-transparent cards and containers
- Soft background blur (where possible)
- Rounded corners
- Subtle borders
- Gentle shadows for depth

### Avoid
- Heavy shadows
- Sharp edges
- Flat, boxy layouts

---

## 🎨 Color Guidelines

- Primary palette:
  - Deep charcoal / dark gray
  - Muted blues or purples (subtle accents only)
- Accent colors:
  - Used sparingly for actions (buttons, selections)
- Crisis screens:
  - Calm supportive tones
  - ❌ No red panic screens
  - ❌ No flashing or alarming visuals

---

## ✍️ Typography

- Clean, readable sans-serif fonts
- Medium font weights preferred
- Generous line spacing
- Avoid:
  - All caps
  - Dense text blocks
  - Small font sizes

---

## 🧭 Layout & Spacing

- Centered content
- Generous padding and margins
- One primary focus per screen
- Plenty of breathing space

**Rule:**  
If it feels crowded → remove something.

---

## 🧠 UX Principles

All interactions should feel:
- Calm
- Respectful
- Non-judgmental
- Optional (never forced)

### Required UX Behaviors
- No sudden popups
- No aggressive prompts
- Easy dismissal of suggestions
- Clear navigation between screens

---

## ⚠️ Safety Screen UX

- Supportive, not alarming
- Clear messaging
- High readability
- Transparent actions
- Always include non-medical disclaimer

---

## 🚫 Things We Explicitly Avoid

- Bright colors
- Gamification
- Animations that distract
- Clinical or medical language
- Information overload
- Multi-step forms

---

## ✅ UI Acceptance Check (Quick Self-Test)

Before marking a screen “done”, ask:
- Would this feel safe to use late at night?
- Is it calm and uncluttered?
- Does it feel premium, not hacky?
- Does it respect the user’s emotional state?

If unsure → simplify.

---

## 🏁 Final Note

Unsaid’s UI should feel like a **quiet, supportive space**, not an app trying to impress.

Clarity > complexity  
Calm > cleverness  
Empathy > features
