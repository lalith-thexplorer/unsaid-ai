# Unsaid
*A space for what you can’t say out loud.*

Unsaid is a privacy-first, non-medical AI emotional support web app.  
It helps users express difficult emotions through empathetic listening,
gentle coping suggestions, and reflective insights — without login or data tracking.

## Key Features
- Mood badge check-in
- Empathetic AI chat
- Crisis-aware safety support
- Short-term mood insights
- Reflection export for professionals

## Tech Stack
- Streamlit (Frontend)
- Python
- Gemini 1.5 Flash API
- Plotly
- FPDF
